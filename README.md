## Run locally

1. Clone this repository.
2. Open `index.html` in a browser, or run a local static web server.
3. No package installation or build command is required.

## Publish using GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Choose **Deploy from a branch** under Build and deployment.
3. Select branch `main` and folder `/(root)`.
4. Save and wait for GitHub Pages to publish the site.
5. Copy the exact live URL displayed in Pages settings.
