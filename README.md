## Run locally

1. Clone this repository.
2. Open `index.html` in a browser, or use a local static server.
3. No build step or package installation is required.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The public URL will be shown in the Pages settings.
